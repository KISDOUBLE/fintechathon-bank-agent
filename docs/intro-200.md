# 作品简介（200 字以内）

令行是一个不会乱动钱的银行智能体：大模型只负责听懂和提议，资金动作由确定性代码在权限边界内执行。系统覆盖转账、账单、理财、卡片、订阅、生日联动六个场景；三色判定逐条可解释——黄色二次确认，红色多因子验证，越限与越权直接拦截。权限校验下沉到工具层，配合注入防御、审计哈希链、身份令牌和异常熔断。零第三方依赖，断网可跑，87 项单元测试与 59 条端到端用例全部通过。

## 名字说明

- 中文名：令行
- 出处：令行禁止——该执行的执行，该拦的拦
- 英文名：LingXing
- 一句话：一个不会乱动钱的银行智能体
