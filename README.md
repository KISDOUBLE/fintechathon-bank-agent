# 银行 AI 智能体 · FinTechathon 2026

一个**不会乱动钱**的银行智能体：自然语言进来，受权限约束的确定性执行出去。

- 大模型只负责**理解与提议**，不持有账户凭证，也不能发起资金动作。
- 每一笔资金动作在**工具执行层**独立鉴权，提示词无法绕过。
- 每个颜色判定都能说出**规则名 + 具体阈值**。
- 全链路审计用**哈希链**，改一条记录会断链。

零第三方依赖，只用 Node.js 内置模块（`node:sqlite` / `node:http` / `node:crypto` / `node:test`）。断网可跑，干净机器可起。

## 快速开始

```bash
node scripts/smoke.mjs      # 离线冒烟：7 项
node scripts/ci.mjs         # 本地 CI：密钥扫描 + 单测 + 冒烟
node src/server.mjs         # Web 演示：http://127.0.0.1:8787
node src/channels/webhook.mjs   # 渠道验证：POST http://127.0.0.1:8788/webhook
```

需要 Node ≥ 22.5（用到 `node:sqlite`）。当前验证版本 v24.21.0。

配真实模型（可选，不配则走纯规则链路，功能不降级）：

```bash
export DEEPSEEK_API_KEY=sk-...
export DEEPSEEK_MODEL=deepseek-flash   # DeepSeek-V4.1-Flash-1017
node scripts/llm-test.mjs
```

密钥只从环境变量读。`.env` 已进 `.gitignore`，CI 会扫描源码与文档中的密钥残留。

## 架构（请求经过的顺序）

```
渠道（Web / webhook）
  → 输入护栏      归一化（全角/零宽）+ 注入检测
  → 意图解析      规则优先，置信度不足才问模型
  → 三色判定      纯函数，只读快照，输出 rule + detail
  → 权限分级      L0/L1/L2/L3/X，金额与新设备会抬升
  → 人工确认      L2 二次确认，L3 多因子（演示用模拟验证码）
  → 工具层执行    再次鉴权，复式记账，幂等键
  → 审计          结构化 + 哈希链
```

### 三色判定：九条规则，个个带数字

| 维度 | 规则 | 默认阈值 |
| :--- | :--- | :--- |
| 单笔金额 | `R-AMT-SINGLE-WARN` / `R-AMT-SINGLE-BLOCK` | ¥5,000 / ¥50,000 |
| 日累计 | `R-AMT-DAILY-WARN` / `R-AMT-DAILY-BLOCK` | ¥10,000 / ¥20,000 |
| 收款人 | `R-PAYEE-FIRST-WARN` / `R-PAYEE-FIRST-BLOCK` | 首次 ≥ ¥1,000 / ≥ ¥20,000 |
| 可逆性 | `R-IRREVERSIBLE` | 转账、取消订阅不可自助撤销 |
| 频次 | `R-FREQ-10M-WARN` / `R-FREQ-24H-BLOCK` | 10 分钟 >3 笔 / 24 小时 >5 笔 |
| 终端 | `R-DEVICE-NEW` | 新设备 2 小时内 |

任一红色规则 → 拦截；有黄色 → 确认后执行；全绿 → 直接执行。

### 权限分级

| 级别 | 判定 | 本项目的实现 |
| :--- | :--- | :--- |
| L0 | 公开信息 | 汇率查询 |
| L1 | 本人只读 | 余额、流水、账单、订阅列表 |
| L2 | 本人中风险写 | 普通转账、取消订阅 |
| L3 | 本人高风险写 | 金额 ≥ ¥5,000 的转账、新设备发起的写操作 |
| X | 越权/跨域 | 跨用户访问、未知工具、日累计超硬上限 |

关键点：`authorize()` 在 `ToolRegistry.execute()` 里被**再执行一次**。即使有人绕过对话层直接调用工具，`confirmed: false` 或 `mfaVerified: false` 依然会被拒绝。

## 防幻觉与注入

- **注入**：NFKC 归一化 + 零宽剥离，中英双语规则，单条高危或两条中危组合即拦截；命中的规则名写进回复。
- **间接注入**：工具返回内容一律包成 `<untrusted>`；备注字段落库前先过护栏，含指令内容直接拒绝。
- **幻觉**：回复模板只引用工具返回值；`checkGroundedness()` 可校验回复中的每个金额是否出现在工具结果里。
- **不可执行**：模型提出的工具调用走同一套 `ToolRegistry`，没有旁路。

真实模型联调：`node scripts/llm-test.mjs`（需密钥），验证「模型真的调了工具」「未确认的转账被拒绝」。

实测输出（2026-10-27，`deepseek-flash`）：

```
✔ 意图分类：口语化账单请求（2000ms） — intent=bill_analyze conf=0.93
✔ 工具循环：账单分析（必须真的调工具）（3555ms） — steps=1
```

## 已知限制

1. MFA 是演示实现（本地生成验证码），未接真实短信/人脸 SDK。
2. 账本是 Mock 复式记账，未对接真实核心系统。
3. 单进程内存会话，未做多实例会话共享。
4. 意图解析覆盖 6 类，长对话意图漂移未量化。
5. 汇率等外部服务尚未接入（下一步）。
