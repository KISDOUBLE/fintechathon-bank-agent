## 02 答辩 PPT（10 页 / ≤10 分钟）

建议结构：

1. 封面 + 一句话定位
2. 问题：聊天式银行助手的三类失败（只说不做 / 说做就做 / 做了没记录）
3. 架构：渠道 → 护栏 → 解析 → 判定 → 权限 → 执行 → 审计
4. 三色判定：绿/黄/红 + 硬拦截，每条规则带阈值
5. 权限下沉：工具层再判一次（演示代码片段）
6. 多步任务：批量取消订阅 + 任务级授权
7. 攻防演示：注入 / 越权 / 冒用身份，逐条被拦
8. 评测结果：87 单测 / 59 用例 / 红队 18 条
9. 限制与边界：MFA 模拟、无 HTTPS、注册未验证
10. 收尾：可复现命令 + 仓库地址
